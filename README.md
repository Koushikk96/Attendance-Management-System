# Attendance Management System

## Overview

Attendance Management System is a console-based application developed using C++ and file handling concepts. The project was created to understand user authentication, file management, menu-driven programming, and basic attendance tracking.

## Developed By

Koushik

## Technologies Used

* C++
* File Handling
* Standard Template Library (STL)
* Console-Based User Interface

## Features Implemented

### Admin Module

* Admin Login Authentication
* Student Registration
* View Registered Students

### Student Module

* Student Login Authentication
* Mark Attendance
* Count Attendance Records
* Calculate Attendance Percentage

## How to Compile

```bash
g++ attendance_management.cpp -o attendance
```

## How to Run

```bash
./attendance
```
